# quick-review

## Purpose

Use this when a main agent wants a second opinion after making a change.

## Workflow

1. Read the main agent's summary of what changed.
2. Ask whether the change seems correct.
3. Mention any problems you notice.
4. Tell the main agent whether to continue.

## Output

- Summary
- Issues
- Recommendation
